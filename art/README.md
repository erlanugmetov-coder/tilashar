# Графика карты города · Модуль 1 (чат №4, 22.11.2026)

Стиль: 2D-мультяшная изометрия, жирный контур, тёплые цвета (по образцу Ерлана — Алматы, горы, Көктөбе).
Нарисовано в ElevenLabs, модель **Seedream 5.5**, листами по 9 объектов (3×3) — у объектов одного листа одинаковые ракурс, свет и масштаб.

- `map/` — 159 объектов + `panorama.webp` (фон: горы и Көктөбе). WebP, до 600 px, прозрачный фон. Всего ≈ 6 МБ.
- `sheets/` — исходные листы (на случай перерезки).
- Резка: `tools/art/grid_cut.py лист.png папка 3 3 имя1,имя2,…` (каждый кусок присваивается клетке сетки по центру масс).
- Какие объекты на каком листе — `tools/art/sheets.txt`.
- Список и описания объектов — документ проекта `claude/tilashar-tz-grafika.md` (имена файлов = коды из ТЗ).

## Что дальше
Встроить в карту вместо рисунков кодом (функции `v*` в main.html, построек в `CTASK` поле `b:`). Сначала — тестовая страница: кусок Центра «было / стало».

## Замечания
- Под частью объектов есть кусочек земли/травы (вольеры, деревья, клумбы) — так задумано моделью, на карте смотрится нормально.
- `library` — флажок без символов; `flag` — цветной вымпел без символов.
- Транспорт: вид сбоку (вправо) и спереди; влево — зеркалить кодом.
